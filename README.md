# Sky Novels SSR Wrapper
هذا المشروع عبارة عن خادم Node.js يقوم بتحويل بيانات الـ API الخاصة بتطبيق "سماء الروايات" إلى صفحات HTML جاهزة.
الهدف: تمكين تطبيقات الـ Scraping (مثل شاي الروايات) من قراءة المحتوى الذي لا يمكنها قراءته من تطبيق React SPA الأصلي.

## طريقة التشغيل محلياً:
1. تأكد من تثبيت Node.js.
2. افتح المجلد في الـ Terminal.
3. نفذ الأمر: `npm install`
4. نفذ الأمر: `npm start`
5. افتح المتصفح على: `http://localhost:3000`

## النشر (Deployment):
يمكنك رفعه على Render.com أو Vercel أو Railway كـ Node.js App.
